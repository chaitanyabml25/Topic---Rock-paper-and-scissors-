# Topic---Rock-paper-and-scissors-
**Python Experiential Learning**
**ProjectOverview **
The Rock, Paper, Scissors Game is a Python-based project designed to simulate the classic Rock, Paper, Scissors game between a player and the computer. The system will allow the player to select one of three choices — Rock, Paper, or Scissors — while the computer randomly generates its own choice. 
It will compare both choices according to the game rules, declare the winner, update the score, and let the user play multiple rounds. **Objectives** 
Allow the player to input their choice (Rock, Paper, or Scissors) Generate a random choice for the computer Compare player and computer choices based on game rules Declare the result of each round (win, lose, or draw) Keep track of and update the score across rounds Allow the user to play multiple rounds interactively Provide a user-friendly, interactive gameplay experience Project Phases 
**Phase 1** – Problem Understanding & Logic Designing Problem statement Objectives Algorithm Flowchart/Pseudocode Python logic understanding GitHub repository setup 
**Phase 2 **– Coding & Testing Python implementation Testing and debugging Game logic validation (rule comparisons, edge cases) Score tracking and round management 
**Phase 3** – Deployment Final project preparation Deployment Final testing and documentation Technologies Python GitHub random module (for computer's choice) Project Status
